Glosario de GitLab

Término Definición
GitLabPlataforma DevOps para control de versiones, CI/CD y gestión de proyectos.
Group (Grupo)Entidad que organiza proyectos y usuarios con permisos centralizados en GitLab.
Subgroup (Subgrupo)Grupo dentro de otro grupo en GitLab, utilizado para organizar proyectos de manera jerárquica.
ProjectUn contenedor para un repositorio Git.
RepositorioLugar centralizado donde se almacena y gestiona el código fuente de un proyecto.
Branch (Rama)Línea de desarrollo independiente que diverge de la principal para trabajar en nuevas características o correcciones.
Branching Strategy (Estrategia de ramificación)Un flujo de trabajo de desarrollo de software dentro del contexto de Git.
Protected Branch (Rama protegida)Rama con restricciones que impiden cambios directos sin revisión o aprobación previa.
CommitAcción de guardar cambios en el repositorio con un mensaje descriptivo.
MergeProceso de combinar cambios de diferentes ramas en una sola.
Merge Request (Solicitud de Fusión)Propuesta para fusionar cambios de una rama a otra, permitiendo revisión y discusión.
IssueRegistro de tareas, errores o solicitudes de mejora en un proyecto.
PipelineSecuencia automatizada de procesos en GitLab CI/CD que compila, prueba y despliega código.
CI/CDContinuous Integration/Continuous Deployment (Integración Continua y Despliegue Continuo); prácticas que automatizan pruebas y despliegues de código.
RunnerMáquina que ejecuta trabajos en una pipeline de GitLab CI/CD.
Milestone (Hito)Punto clave en el cronograma de un proyecto que marca la finalización de un conjunto de tareas.
Tag (Etiqueta)Marcador en la historia del repositorio que señala versiones específicas del código.
WikiSección en GitLab para documentación colaborativa del proyecto.
ForkCopia de un repositorio que permite experimentar sin afectar el original.
SnippetFragmento corto de código reutilizable que puedes guardar, compartir o insertar fácilmente.
WebhookMecanismo que permite a GitLab enviar notificaciones a servicios externos cuando ocurren eventos específicos.
SSH Key (Clave SSH)Secure Shell Key (Clave de Shell Seguro); credencial de seguridad que permite autenticación segura y acceso al repositorio sin necesidad de contraseñas.
GPG Keys (Claves GPG)GNU Privacy Guard Keys (Claves de Protección de Privacidad GNU); claves de cifrado usadas para firmar commits y etiquetas, garantizando autenticidad.
Web IDEWeb Integrated Development Environment (Entorno de Desarrollo Integrado Web); entorno de desarrollo que corre directamente en el navegador sin necesidad de instalación.
Git LFS (Large File Storage)Git Large File Storage (Almacenamiento de Archivos Grandes de Git); extensión de Git para manejar archivos grandes de forma más eficiente.
Personal Access Token (Token de acceso personal)Credencial utilizada para autenticar y acceder a la API de GitLab sin necesidad de una contraseña.
Member (Miembro)Usuario agregado a un proyecto o grupo con permisos específicos en GitLab.
